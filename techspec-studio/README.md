# SpecFlow · 技术方案工作台

从需求文档与项目源码创建前端技术方案、后端技术方案和测试用例。

## 启动

无需安装运行依赖，Node.js 14 及以上即可：

```sh
cd techspec-studio
node server.cjs
```

打开 http://localhost:5178 。也可以使用任意静态服务器托管 `dist/`。

## 已实现

- 多项目独立工作空间，首次打开附带可替换的企业协作平台示例。
- PDF（文本型）、DOCX、MD、TXT、JSON、CSV 导入与真实文本解析；UI 图片作为参考附件。
- 项目 ZIP / 文件夹导入，保留源码路径，过滤依赖、构建产物及常见密钥文件。
- 前端方案、后端方案、测试用例可组合生成，分别保留与切换。
- 预设四部分目录：相关文档、需求概览、方案设计（按模块）、排期。
- 自定义章节、子目录、顺序与模块，保存和复用目录模板。
- Markdown 阅读、直接编辑、复制、文件导出；历史版本可继续编辑。
- IndexedDB 持久保存项目、资料、模板和历史；工作空间 JSON 备份导出。
- 支持桌面与窄屏布局、键盘操作和弹窗焦点约束。

方案默认采用精简图文结构：模块表、关键结论、Mermaid 架构 / 测试流程图与排期图。图表在阅读预览中绘制，导出 Markdown 时保留可编辑源码；不支持的语法或绘制失败会保留源码供修改。

当前托管位置、运行结构和完整部署步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。

## 生成方式

默认使用**本地草稿**：清理 OCR 注释与展示标签，保留模块内多行规则和子章节；按需求相关性检索业务源码，列出真实路径、行号、声明和匹配片段，并生成待评审的实施建议。项目 README 等文档也参与源码上下文检索。没有调用语言模型，不会声称完成语义分析或仓库调用链分析。生成按钮和预览均明确标注模式。

在左下角「连接 AI 模型」填写兼容 Chat Completions 的 API Base URL、模型名称和 Key，即可启用 AI。请求从浏览器直接发往配置的服务商，需要服务商允许 CORS。支持 HTTPS；本机服务可用 HTTP。接入特定供应商时可在 `requestAI` 中调整请求参数。

密钥仅保留在当前页面内存，刷新即清除；AI 模式选择保留，刷新后再次生成会要求重新连接，不会自动降为本地草稿。导入文本和代码在点击 AI 生成后发送至配置的服务商；资料预算约 9.6 万字符（不含提示词），先保留需求空间，再按相关性选择业务源码，优先抽取匹配行附近的实现而非平均截取文件开头。生成前显示纳入、截断和未纳入数量；实际请求包含覆盖说明与原始源码行号。UI 图片不发送给模型。提示词要求补充约束进入模块设计和验收，区分现状、复用、修改、新增与资料缺口。返回缺失章节、空章节或未引用真实源码路径时拒绝保存，保留已有结果。模型失败不会静默降级生成草稿。没有提供真实模型凭证，因此仅通过模拟兼容接口验证请求和错误处理，未完成真实付费模型端到端验证。

## 当前边界

这是可运行的个人工作台首版。资料保存在当前浏览器，尚未实现用户管理、团队权限、云端数据库、跨设备同步、Git 远程仓库接入和后台任务队列。扫描 PDF 请先做 OCR。UI 图片可预览但不进行视觉识别。排期是工期建议，需评审确认负责人和日期。

需求单文件上限 20 MB；UI 图片 5 MB；PDF 最多 150 页。源码 ZIP 上限 25 MB，解压源码总量 30 MB，一次最多 300 个代码文件；单个代码文件最多 2 MB / 50 万字符。项目累计最多 400 个文件、10 MB 已解析内容。超过时按业务模块拆分导入。仅过滤常见敏感文件路径，不执行内容级密钥扫描。

清理网站数据会删除本地项目，请导出需要保留的方案或工作空间备份。备份含导入的源码与需求，不含 API Key。

## 验证

运行依赖全部已打包在 `dist/assets/`，测试依赖仅用于开发（请使用 Node.js 22 或更高版本）：

```sh
npm install
npm test
```

集成检查使用 JSDOM、fake-indexeddb 与真实的 PDF、Word、ZIP 解析器，验证多产物生成、自定义目录、编辑导出、隔离项目、历史恢复、HTML 清洗、模型请求和错误处理。回归场景包括 190 个配置文件中的地图业务源码、文件后半段的坐标转换函数、OCR 注释和嵌套需求、上下文预算、空方案拒绝保存、刷新后的 AI 模式及 Mermaid HTML 标签清洗后保留文字。本环境无法连接浏览器，尚未完成浏览器视觉与跨设备实测。

## 文件

- `dist/index.html`：入口
- `dist/styles.css`：响应式工作台样式
- `dist/core.js`：资料提取、目录、草稿与 AI 提示词
- `dist/diagrams.js`：Mermaid 图表安全渲染与失败回退
- `dist/app.js`：界面、文件解析、存储和模型调用
- `server.cjs`：本地静态服务器（只绑定 loopback）
- `tests/run.cjs`：功能与集成验证

第三方依赖版本和许可证见 `THIRD_PARTY.md`。

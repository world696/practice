## Communication

- The user usually communicates in English. Reply in Simplified Chinese by default.
- If the English contains clear mistakes, briefly suggest a more natural phrasing before answering.
- Keep explanations concise.

## Workflow

- Read the relevant code before making changes.
- Explain your understanding before implementation.
- Don't modify unrelated code.
- Ask for confirmation before making large refactoring.
- Don't run build unless explicitly requested.

## Coding Guidelines

- Follow the existing project style.
- Keep business logic outside UI components.
- Prefer reusable composables.
- Keep functions focused and easy to read.
- Preserve existing behavior unless explicitly requested.
- Don't modify unrelated code.
- Avoid unnecessary refactoring.
- Minimize the scope of changes.
- Do not use CSS Grid or the gap property.
